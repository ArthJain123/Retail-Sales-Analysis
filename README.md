# 🛍️ Retail Sales Analysis

## 📌 Project Overview

This project is created by me as a personal Data Analysis project to analyze retail sales data and generate meaningful business insights.

The project includes data cleaning, feature engineering, exploratory data analysis (EDA), customer analysis, sales analysis, revenue analysis, and a Machine Learning model to understand relationships within the sales data.

---

## 🎯 Objectives

* Perform data cleaning and preprocessing.
* Analyze retail sales performance.
* Identify top-selling and high-revenue products.
* Analyze customer purchasing behavior.
* Explore monthly sales trends.
* Build a Linear Regression model for prediction.
